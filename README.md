# Pygargue00fr-Better-Than-Adventure---Localisation-Française
Une traduction complète de Better Than Adventure, couvrant actuellement la version 8.0.1 avec support intégré pour de nombreux mods de la communauté.

Mods inclus :
-Better than Aether
-Stardew Farming
-Farlanders
-The Fool
-Stardew Farming
-Better than Rain
-Dyables
-Improved Signs
-Better than Waila
-e4BTA
-e4BTA_voice

Téléchargement : Assurez-vous d'avoir un fichier zip intitulé fr_FR, renommez le si nécessaire sinon vous risquez un plantage au lancement du jeu.
